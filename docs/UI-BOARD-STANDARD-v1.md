# Estiban Creations Shared UI Contract v1.1
Effective 2026-10-07. Architect-approved.

For every interactive system page:
- Keep the persistent left sidebar on every V1/V2/V3 board; include the top collapse/expand control.
- Top command bar includes global Search, + Create, and notification bell.
- Do not put user/login/profile identity in the top bar.
- User/profile/account control is locked in the sidebar immediately above THELMA; THELMA remains below it.
- V1 and V3 remain selectable alternates when V2 is chosen as primary.
- Approved primary boards may not be replaced by older shells without explicit Architect approval.
- Runtime/live connection claims require separate verification; UI approval is not runtime certification.

VisionWeaver locks: Worlds & Locations V2 primary; Design Studio V2 primary.
Canonical detailed standard: VisionWeaver standards/UI-BOARD-STANDARD-v1.md and Master-System-Buildout 02-SYSTEM-SPECIFICATIONS/UI-BOARD-STANDARD-v1.md.
